# CopyPathRust

一个用 Rust 编写的 Windows 右键菜单小工具，提供「复制路径」「复制文件名」「替换文件」「在此打开终端」等常用操作。

- 单文件 exe，约 100KB，绿色免安装
- 全部写入 `HKCU`，**不需要管理员权限**
- 双击 exe 即可安装 / 卸载，无需命令行
- 纯 Win32 FFI 实现，无第三方运行时依赖

---

## 功能

### 文件右键

| 菜单项 | 说明 |
|---|---|
| 复制路径 | 复制文件的完整路径，如 `D:\Proj\src\main.rs` |
| 复制文件名 | 复制文件名，如 `main.rs` |
| 复制所在目录 | 复制文件所在的目录，如 `D:\Proj\src` |
| 复制带引号路径 | 复制 `"D:\Proj\src\main.rs"`，适合粘贴到命令行 |
| 替换为剪贴板中的文件 | 用当前文件覆盖剪贴板中指定路径的文件，被覆盖文件保留原名 |

> **小技巧**：按住 `Shift` 点击「复制路径」，等价于「复制带引号路径」。

### 文件夹右键

| 菜单项 | 说明 |
|---|---|
| 复制路径 / 复制文件夹名 / 复制所在目录 / 复制带引号路径 | 同上 |
| 在此打开 PowerShell 7 | 仅当检测到 `pwsh.exe` 时出现 |
| 在此打开 Windows PowerShell | 系统自带，始终出现 |
| 在此打开命令提示符 | 系统自带，始终出现 |
| 在此打开 Cmder | 仅当检测到 `Cmder.exe` 时出现 |

### 文件夹空白处右键

| 菜单项 | 说明 |
|---|---|
| 复制当前路径 / 复制当前路径(带引号) | 复制当前文件夹的路径 |
| 在此打开各类终端 | 同上 |

cargo build --release
